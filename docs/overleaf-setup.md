# Overleaf import

Overleaf MCP was unavailable. Each package contains its full source tree with `main.tex` at the archive root.

1. In Overleaf, choose **New Project** and **Upload Project**.
2. Upload `deliverables/Overleaf_V1.zip` and name the new project **DIC4 Conference Paper - V1 Initial Draft**.
3. Upload `deliverables/Overleaf_V2.zip` to a separate project named **DIC4 Conference Paper - V2 Revised Draft**.
4. In each project, verify the main document is `main.tex`, select pdfLaTeX or XeLaTeX, and compile.

Both ZIPs were checked locally. The import steps require an Overleaf account.
