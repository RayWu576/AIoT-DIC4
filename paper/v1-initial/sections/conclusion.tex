\section{Conclusion}
The Traffic Timing Assistant combines a three-class decision tree with a phase controller and a feedback path for checking which timing plan took effect. Two proposal-reported synthetic host batches show lower aggregate queue vehicle-seconds with some degraded scenarios, and a separate board check supports feasibility of plan application. Independent reproduction requires the underlying runs and controller traces. Next steps are to integrate structured task input and reporting, strengthen source validation, evaluate the reference rule under the same conditions, and test additional device cases and suitable real-world traffic data.
