## Context
The nine-page proposal is the primary project record. Host results are aggregate summaries, and board findings are qualitative.

## Decisions
Use IEEEtran with BibTeX and TikZ. Preserve each source tree and build its ZIP with main.tex at the archive root. Use proposal page numbers in the evidence ledger. Keep unverified author information out of the paper and student identifiers out of Git.

## Risks
Missing traces and implementation files constrain reproducibility. Missing Overleaf MCP requires import packages. GitHub synchronization depends on credentials and a writable private repository.
