# Why
The Traffic Timing Assistant proposal needs an evidence-based IEEE conference manuscript and a reproducible submission history.

## What Changes
Create a modular paper, vector figures, an evidence ledger and two immutable version snapshots.

## Capabilities
### New Capabilities
- `ieee-paper`: English IEEE conference manuscript.
- `decision-system`: Evidence-based decision design.
- `hardware-execution`: Cycle-boundary execution and readback.
- `experimental-evaluation`: Paired evaluation and evidence limits.
- `version-delivery`: Version-preserved sources and packages.

### Modified Capabilities
None.

## Impact
Paper and documentation only. No simulator or board implementation changes.
